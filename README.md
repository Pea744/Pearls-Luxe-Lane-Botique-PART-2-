## Project Overview

Pearl's Luxe Lane Boutique is a fictional fashion boutique website created
for young adults and girls in emerging adulthood who are interested in
modern, trendy and stylish clothing.

The purpose of the website is to provide customers with an easy way to
learn about the boutique, explore different product categories, make
product enquiries and find contact information.

The website was developed using HTML5 and CSS3. The design uses a pink,
white and burgundy colour palette to create a fashionable and welcoming
appearance.

## Organisation Overview

### Organisation Name

Pearl's Luxe Lane Boutique

### Organisation Description

Pearl's Luxe Lane Boutique is a fictional fashion boutique that provides
stylish clothing and accessories for young adults. The boutique offers
different clothing styles that can be used for casual wear, everyday
outfits and special occasions.

### Mission

Our mission is to provide fashionable and affordable clothing while
helping customers feel confident in what they wear. We aim to provide
different clothing options that suit different styles, occasions and
personal preferences.

### Vision

Our vision is to become a trusted fashion boutique that inspires young
people to express themselves through fashion. We aim to provide stylish
clothing, good customer service and a welcoming shopping experience.

### Target Audience

The target audience is young adult women and girls in emerging adulthood
who are interested in fashionable, modern, trendy and stylish clothing.

## Website Goals and Objectives

The main goals of the website are:

- To introduce customers to Pearl's Luxe Lane Boutique.
- To allow users to explore the available product categories.
- To provide information about the boutique and its mission.
- To make it easy for customers to contact the boutique.
- To allow customers to submit product enquiries.
- To provide a responsive website that can be viewed on different screen
  sizes.

### Key Performance Indicators

The website can be evaluated using the following indicators:

- Number of visitors to the website.
- Number of product enquiries received.
- Number of users viewing the Products page.
- Number of users using the Contact page.
- Successful navigation between website pages.
- Website usability on desktop, tablet and mobile devices.

---

## Website Features and Functionality

The website includes the following pages and features:

### Home Page

Introduces Pearl's Luxe Lane Boutique and provides an overview of the
clothing and services offered.

### About Page

Provides information about the boutique, including its background,
mission, vision, values and what the boutique offers.

### Products Page

Displays the different product categories available at the boutique.

### Enquiry Page

Allows users to enter their name, email address, phone number, product
of interest and message.

### Contact Page

Provides the boutique's email address, telephone number, location and
an embedded map.

### Navigation

The website contains navigation links that allow users to move between
the Home, About, Products, Enquiry and Contact pages.

### Responsive Design

The website uses CSS media queries and responsive images to allow the
website layout to adapt to desktop, tablet and mobile screen sizes.

## Design and User Experience

### Colour Scheme

The website uses a pink, white and burgundy colour palette.

The main colours include:

- Light pink
- Bright pink
- Burgundy
- White

These colours are used consistently throughout the website to create a
fashion-focused and welcoming appearance.

### Typography

The website uses:

- Arial for general body text.
- Georgia for headings.

Different heading sizes are used to create a clear information
hierarchy.

### Layout and Design

The website uses a simple and organised layout. Content is separated
into sections to make information easier to read.

The Products page uses CSS Grid to display product categories in columns.
The navigation uses Flexbox, while media queries change the layout for
smaller screens.

### User Experience

The website includes:

- Clear navigation.
- Descriptive headings.
- Alternative text for images.
- Responsive images.
- Readable typography.
- Hover effects on navigation links and buttons.
- A responsive layout for smaller screens.

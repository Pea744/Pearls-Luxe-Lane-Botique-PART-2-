## Project Overview

Pearl's Luxe Lane Boutique is a fictional fashion boutique website created for young adults interested in modern, trendy and stylish clothing.

The purpose of the website is to introduce the boutique, allow visitors to explore product categories, learn about the business, submit enquiries and find contact information.

The website was developed using HTML5 and CSS3. JavaScript is used for any interactive features implemented in the project. The design uses a pink, white and burgundy colour palette to create a fashionable and welcoming appearance.

## Organisation Overview

### Organisation Name

Pearl's Luxe Lane Boutique

### Organisation Description

Pearl's Luxe Lane Boutique is a fictional fashion boutique that offers stylish clothing and accessories for young adults. The products include different styles suitable for casual wear, everyday outfits and special occasions.

### Mission

Our mission is to provide fashionable and affordable clothing while helping customers feel confident in what they wear.

### Vision

Our vision is to become a trusted fashion boutique that inspires young people to express themselves through fashion.

### Target Audience

The target audience is young adult women who are interested in modern, fashionable and trendy clothing.

## Website Goals and Objectives

The main goals of the website are:

- To introduce customers to Pearl's Luxe Lane Boutique.
- To allow visitors to explore the available product categories.
- To provide information about the boutique and its mission.
- To make it easy for customers to find contact information.
- To allow customers to submit product enquiries.
- To provide a website that can be viewed on desktop, tablet and mobile devices.

### Key Performance Indicators

The website could be evaluated using the following indicators:

- Number of visitors to the website.
- Number of product enquiries received.
- Number of visitors viewing the Products page.
- Successful navigation between website pages.
- Website usability on desktop, tablet and mobile devices.

## Website Features and Functionality

### Home Page

Introduces Pearl's Luxe Lane Boutique and provides an overview of the boutique.

### About Page

Provides information about the boutique, including its background, mission and vision.

### Products Page

Displays the different clothing and accessory categories available.

### Enquiry Page

Provides a form where visitors can enter their details, product of interest and message.

### Contact Page

Provides the boutique's contact information and location details.

### Navigation

Navigation links allow users to move between the Home, About, Products, Enquiry and Contact pages.

### Responsive Design

CSS media queries and responsive layout rules are used to adjust the website for different screen sizes. Images are included to support the presentation of the products.

## Design and User Experience

### Colour Scheme

The website uses light pink, bright pink, burgundy and white to create a consistent fashion-focused appearance.

### Typography

Arial and Georgia are used for body text and headings where implemented in the stylesheet. Different heading sizes help organise information and improve readability.

### Layout and Design

The website uses a structured layout to organise content. CSS Flexbox and Grid are used where implemented, while media queries support layout adjustments for smaller screens.

### User Experience

The website aims to provide:

- Clear navigation.
- Descriptive headings.
- Alternative text for images.
- Readable typography.
- Hover effects on links and buttons.
- A layout that adapts to smaller screens.
